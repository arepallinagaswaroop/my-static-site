!!! Hosting a Static Website with GitHub Pages:

## Objective
Deploy a simple HTML website using GitHub Pages.

## Tools Used
- GitHub Pages

## What I Did
1. Created an `index.html` file with basic content.
2. Created a `style.css` file to style the page.
3. Pushed both files to a new GitHub repository.
4. Enabled GitHub Pages via **Settings → Pages**, selecting the `main` branch and `/ (root)` folder.
5. Accessed the live site using the link provided by GitHub.
